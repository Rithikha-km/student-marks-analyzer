# student-marks-analyzer
## About
A beginner python project that calculates a student's total mark, percentage, grade, highest mark, lowest mark.
## Features
- Calculates total mark
- Calculates percentage
- Determines grade
- Finds highest mark
- Finds lowest mark
## Technologies Used
- Python
## How to run
1. Open project in VS code.
2. Run 'main.py'.
3. Enter student's name ans marks.
4. View the result in the terminal
